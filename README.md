# AutoCorp 설치 안내

AutoCorp 는 도트 사무실에서 AI 직원(Claude·GPT)이 일하는 데스크톱 앱입니다.
설치하고 처음 한 번 **AI 연결**만 하면, 요청 한 줄로 팀장이 팀원에게 일을 나눠 맡깁니다.

## 1. 내려받기

[최신 버전 받기](https://github.com/oma0817/autocorp-releases/releases/latest) 페이지 아래 **Assets** 에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 받을 파일 |
|---|---|
| 맥 (Apple 실리콘 — M1·M2·M3·M4 …) | `AutoCorp-버전-arm64.dmg` |
| 윈도우 10·11 (64비트) | `AutoCorp-Setup-버전.exe` |

> 인텔 맥은 아직 지원하지 않아요. 내 맥의 칩은  메뉴 → **이 Mac에 관하여** 에서 볼 수 있어요.

## 2. 설치

### 맥

1. 받은 `.dmg` 를 열고, **AutoCorp** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어다 놓습니다.
2. 응용 프로그램 폴더에서 AutoCorp 를 엽니다. 처음에는 _"Apple 에서 확인할 수 없어 열 수 없습니다"_ 경고가 뜹니다. 개인이 만든 앱이라 애플 공증을 받지 않아서 그래요.
   - **완료**(또는 취소)를 누르고, ** 메뉴 → 시스템 설정 → 개인정보 보호 및 보안** 으로 갑니다.
   - 아래쪽 _"AutoCorp 이(가) 차단되었습니다"_ 옆의 **그래도 열기** 를 누르고 암호를 넣습니다.
   - 한 번만 하면 다음부터는 그냥 열립니다.

### 윈도우

1. 받은 `AutoCorp-Setup-….exe` 를 실행합니다.
2. _"Windows 의 PC 보호"_ 파란 창이 뜨면 **추가 정보 → 실행** 을 누릅니다. 서명 인증서가 없는 개인 앱이라 그래요.
3. 설치 위치를 고르고 **설치** 를 누릅니다.

## 3. 처음 실행 — AI 연결

1. 앱을 켜면 **AI 연결** 창이 뜹니다 (이미 연결돼 있으면 건너뛰어요).
2. 쓸 AI 를 고릅니다. 하나만 있어도 되고, 둘 다 쓰면 한쪽 한도가 찼을 때 다른 쪽이 이어서 해요.

| AI | 필요한 것 |
|---|---|
| **Claude** (Anthropic) | Claude Pro·Max 구독 **또는** Anthropic API 키 |
| **GPT** (OpenAI) | ChatGPT Plus·Pro 구독 **또는** OpenAI API 키. 처음 설치할 때 [Node.js](https://nodejs.org) 가 필요해요 |

3. 각 AI 를 연결합니다.
   - **설치하기** — 앱 안의 작은 터미널 창에서 공식 설치가 진행돼요. 끝날 때까지 기다리세요.
   - **로그인** — 브라우저가 열리면 구독 계정으로 로그인하고 앱으로 돌아오세요.
   - 구독이 없으면 **API 키** 를 고르고 키를 붙여 넣으세요. 쓴 만큼 요금이 나가요. 키는 이 컴퓨터의 키체인에 암호화해 보관해요.
   - 초록 점(●)이 켜지면 연결된 거예요.
4. 직원들이 일할 **프로젝트 폴더**를 고르고 동의하면 팀장이 출근합니다.
5. 아래 입력창에 할 일을 한 줄로 쓰고 Enter. 예: `README 요약하고 오타 고쳐줘`

## 4. 업데이트

새 버전이 나오면 위쪽 버전 표시 옆에 알림이 떠요. 버전 표시를 누르면 직접 확인할 수도 있어요.

- **윈도우**: 새 버전을 알아서 받아 둡니다. **재시작해서 업데이트** 를 누르면 끝이에요.
- **맥**: **새 버전 받기** 를 누르면 `.dmg` 가 내려받아져요. 열어서 AutoCorp 를 응용 프로그램 폴더에 다시 끌어다 놓고 **대치** 를 고르세요. 설정과 직원 명단은 그대로 남아요.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 맥에서 _"손상되었기 때문에 열 수 없습니다"_ | 터미널에서 `xattr -cr /Applications/AutoCorp.app` 을 실행한 뒤 다시 여세요 |
| AI 연결에서 GPT **설치하기** 가 안 돼요 | [Node.js](https://nodejs.org) 를 먼저 설치하고 앱을 다시 켜세요 |
| 직원 카드에 _"연결이 안 돼 있어요"_ | 위쪽 **⚙ 설정 → AI 연결** 에서 로그인하거나 API 키를 넣으세요 |
| 직원 카드에 ✋ | 직원이 허락을 구하는 중이에요. 카드의 **허락**/**거부** 를 누르세요 |
| 오른쪽 **작업** 탭에 빨간 카드 | 카드 안내 문장 속 버튼을 순서대로 누르면 돼요 |
| 사용 한도가 찼어요 | 위쪽 게이지에서 풀리는 시각을 확인하세요. 다른 AI 가 연결돼 있으면 그쪽이 이어서 해요 |
